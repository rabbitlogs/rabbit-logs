# 이미지 판단 가이드 — 글을 읽고 틀과 색을 고른다

`image-rules-final.md`가 "어떻게 그리는가"의 규칙이라면, 이 문서는 그 앞 단계 —
**"이 글엔 어떤 틀과 색을 쓸 것인가"를 판단하는 절차**다.

핵심 문제 두 가지를 겨냥한다.
1. 습관적으로 `numbering_rows`(넘버링)로 손이 가서 대부분의 이미지가 번호 나열이 된다.
2. 기본색이 늘 청록으로 고정돼 모든 글의 이미지가 초록 계열로 보인다.

두 문제 다 "새 기능이 없어서"가 아니라 "판단 단계를 건너뛰어서" 생긴다. 틀 매핑표도,
6단계 팔레트도 이미 있다. 안 쓰였을 뿐이다.

---

## 1단계 — 글을 읽고 관계를 한 단어로 규정한다

이미지를 열기 전에, 이 이미지가 말하려는 게 무엇인지 **관계 한 단어**로 적는다.
`image-rules-final.md`의 선택 순서 1번과 같다. 넘버링을 부르기 전에 반드시 이걸 먼저 한다.

| 글에서 이런 신호가 보이면 | 관계 | 넘버링이 아니라 이 틀 |
|---|---|---|
| "먼저 … 그다음 … 마지막" 순서가 핵심 | 순차 | 파이프라인 / 넘버링(순서형·타임라인형) |
| "예전엔 … 지금은 …" 상태가 바뀜 | 변화 | Before/After 비교형 |
| "A는 이렇고 B는 저렇다" 맞대응 | 대립 | 가운데 대칭 비교형 |
| "…가 다시 …로 돌아온다" 되돌아옴 | 순환 | 순환형 |
| "…은 …를 포함한다" 위가 아래를 품음 | 포함 | 계층형 |
| "이런 것들이 있다" 순서 없는 나열 | 병렬 | 아이콘 그리드 / 2x2 카드 |
| "원래 데이터가 이렇게 지저분" | 데이터 문제 | 미니 표 직접 그리기 |
| 두 기준으로 4칸 분류 | 2축 분류 | 매트릭스 |

**판단 규칙:** 넘버링(순차)은 "먼저/그다음/마지막"이 실제로 있을 때만 쓴다.
"이유 3가지", "특징 4가지"처럼 순서가 없는 나열에 번호를 붙이면, 없는 순서를
있는 것처럼 보이게 만드는 오독이다. 이때는 카드나 아이콘 그리드로 간다.

## 넘버링을 써도 되는 경우의 변형 (한 틀에 몰지 않기)

순차가 맞아 넘버링을 쓰기로 했어도, 늘 같은 세로 배지 나열로 가지 않는다.
글 성격에 맞춰 아래 넷 중에서 고른다.

| 변형 | 언제 |
|---|---|
| 순서·프로세스형 (세로 배지 + 연결선) | 단계 사이 인과·흐름이 중요할 때 |
| 가로 타임라인형 | 단계가 시간축을 따라 가고 가로 폭이 넉넉할 때 |
| 2x2 병렬 카드형 | 항목이 4개 안팎이고 세로를 짧게 (모바일) |
| 아이콘 결합형 | 각 단계가 추상적이라 시각 단서가 이해를 도울 때 |

- 같은 변형을 연속 3개 이미지 넘게 쓰지 않는다.
- 순서가 아니면 애초에 넘버링이 아니다(위 표로 돌아간다).

---

## 2단계 — 글의 주제로 기본색을 정한다 (초록 쏠림 해소)

`image-rules-final.md`의 "단색 명도차로 통일" 규칙은 유지한다. 색 충돌을 막는
좋은 규칙이다. 문제는 그 단색이 항상 청록이라는 것뿐이다.

**해법: 글이 다루는 SAP 모듈(또는 주제)로 기본색을 바꾼다.** 한 이미지 안은 여전히
한 색 명도차로 통일되지만, 글이 바뀌면 색이 바뀐다.

| 글 주제 / 모듈 | 기본색 | 배지·강조(진한 톤) | 넓은 채움(옅은 톤) |
|---|---|---|---|
| PP 생산 · 조직구조 · 기초 개념 | 청록 | `#234b45` | `#b8d0ca` |
| MM 자재 · 재고 · BOM · 물류 | 골드 | `#8f5c1d` | `#f7e6cd` |
| CO 원가 · QM 품질 · 오류/예외/리스크 | 베리 | `#7a3950` | `#ecd5dd` |
| 통계 · 시험/자격 · 일반 | 청록 또는 주제색 | 상동 | 상동 |

- **배지에 흰 글자를 얹을 땐 반드시 진한 톤(1단계)을 쓴다.** 특히 골드는 중간톤
  (`#d99441`)에 흰 글자를 얹으면 대비가 무너진다. 배지엔 `#8f5c1d`.
- 넓은 카드 배경은 옅은 톤 + 잉크색 글자(`#25302b`)로. 옅은 칸에 흰 글자 금지.
- 강조가 필요하면, 기본색과 **다른 축의 색을 좁은 면적에 1곳만** 쓴다.
  예: 청록 프로세스 4단계 중 "오류 발생" 단계만 베리 배지로.

### 이 배정이 통과하는지 (WCAG 대비)

| 조합 | 대비율 | 기준 |
|---|---|---|
| 흰 글자 / 진한 청록 `#234b45` | 9.71 | 통과 |
| 흰 글자 / 진한 골드 `#8f5c1d` | 5.65 | 통과 |
| 흰 글자 / 진한 베리 `#7a3950` | 8.30 | 통과 |
| 잉크 글자 / 옅은 골드 카드 `#f7e6cd` | 11.17 | 통과 |
| 잉크 글자 / 옅은 청록 카드 `#b8d0ca` | 8.41 | 통과 |
| 잉크 글자 / 옅은 베리 카드 `#ecd5dd` | 9.85 | 통과 |

세 축 모두 본문 기준(4.5)을 여유 있게 넘는다. 단, 골드는 배지 톤을 1단계로
고정하는 조건에서만 성립한다.

---

## 3단계 — 두 줄로 자기 점검하고 그린다

이미지를 그리기 직전, 아래 두 줄을 채울 수 있어야 한다. 못 채우면 틀 선택이 틀린 것이다.

- 이 이미지의 관계는 ____ 이고, 그래서 ____ 틀을 쓴다.
- 이 글은 ____ 주제라 기본색은 ____ 이다. (청록이 아니라면 왜 청록이 아닌지 자명해야 한다.)

특히 "넘버링을 쓴다"고 적었다면, 그 옆에 "순서가 있기 때문"이라는 근거가 붙어야 한다.
근거가 "익숙해서"라면 카드나 아이콘 그리드로 돌아간다.

---

## 요약

- 넘버링은 **순서가 실제로 있을 때만**. 나열엔 카드/아이콘 그리드.
- 넘버링을 써도 세로 배지 하나로 몰지 말고 4변형에서 고른다.
- 기본색은 **글의 모듈로** 정한다(PP=청록, MM=골드, CO·QM/예외=베리). 한 이미지 안은
  여전히 단색 명도차로 통일한다.
- 배지=진한 톤+흰 글자, 넓은 면=옅은 톤+잉크 글자. 옅은 칸에 흰 글자 금지.
